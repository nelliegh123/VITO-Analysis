# VITO-Analysis
Code meant to be used together with ROOT files generated by the G$\textsc{eant}$4 simulations presented in the repository `*VITO-ISODLE*`. The simulations are performed for a specific setup (detectors, sample, and magnetic field), but do not assume anything about the $\beta$-decay. That information is only introduced in this step, named the Analysis. This means that a single G$\textsc{eant}$4 simulation, can be used to study multiple different decays. Only if the geometry changes, will the simulation need to be re-run.  

## Purpose 
The purpose of this code is to provide an option where G<small>eant</small>4 is not needed in order to evaluate the results from simulation. The workflow is the following:
1. A specific experimental setup is built in `*VITO-ISODLE*` and a G$\textsc{eant}$4 simulation is performed
2. The resulting ROOT files are uploaded to this repository
3. The energy spectra of the $\beta$-decay to be studied is uploaded
